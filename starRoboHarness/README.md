# starRoboHarness research website

The publishable static site lives at the `starRoboHarness/` repository root and is served at <https://jackailab.github.io/Projects/starRoboHarness/>. The `dist/` URL redirects to the new location. The complete Chinese page lives at `zh/`.

The September 2026 paired result tables come from the sanitized `exps/data/summary.json` snapshot in the starRoboHarness project. The framework figure, technical report, task-score figure, sanitized case rows, and summary are bundled in `assets/`. Selected replays are labeled as archival media from the earlier five-task release.

Preview with `cd starRoboHarness && python3 -m http.server 4173`.
